# Project Instructions

## Strict Framework Constraint
- This project is 100% **pure static HTML, CSS, and vanilla JavaScript**.
- **DO NOT** use, configure, or introduce **Vite** or React for the HTML.
- Development server is a lightweight Express static server running on port 3000 (`node dev-server.js`).
- Build step runs `node build.js` which copies the static files directly to `dist/`.
