3. About the randomness

The wheel uses your browser's built-in pseudorandom number generator to determine the final angle of each spin. This is the same class of algorithm used widely across the web and is more than adequate for casual decisions — but it is not a cryptographic random number generator, and it should not be treated as one.

Every slice on the wheel is mathematically equal in size, so every option carries the same probability. We do not weight, favor, or manipulate outcomes. However, we cannot guarantee the underlying browser implementation is free from statistical bias, and we make no representation that the results are suitable for scientific, statistical, or regulatory use.

If a spin produces an outcome you do not like, that is not a malfunction — it is the tool doing exactly what it was asked to do. Re-spinning to get a "better" result defeats the purpose of using a random tool in the first place.
